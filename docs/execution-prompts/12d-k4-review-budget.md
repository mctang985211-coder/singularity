# K4：过期任务可复盘，追加执行额度必须授权

你是本票实现主代理，工作区和检查沿用[公共合同](README.md)。修改前保存基线；核对 K3 已验收。本文件为完整合同，不顺带实现 A5 自动扫描/新 Diagnosis 协议或 A6 supervisor/task_recover。

## 最小选择

复盘使用现有 reviewer 每 store 次数额度（默认 1）及单次 watchdog，不继承业务根截止。业务 Run、候选实验仍计原 store 的累计执行账；需要继续时，人可以明确追加其总上限。无需新维护 graph、新 budget epoch、资金转移、自动续费或第二预算账。原 Task/Run/Review 不复活、不改验收，旧费用不清零。

## 固定入口与归属

1. 现有 reviewer 调用链核对的是自身剩余次数和单次超时；原根已截止/用完 Run 数不阻止只读复盘。角色/读取域/真实来源校验不变。K4 用现有可触发的 review 源验收，A5 再替换触发策略和精确源协议；不要提前复制一套自动扫描。
2. 新增唯一工具 `task_budget_extend({requestKey, maxRuns?, deadlineAt?})`，只给可信根协调会话，终态亦可调用；store 从会话绑定推导。至少给一个字段：maxRuns 是批准后的总 Run 数正整数，deadlineAt 是批准后的绝对 UTC 时间，不接受增量、相对时长、token 新账或 approved 参数。只允许提高已配置的对应有限上限；未配置表示该维无限，不需要扩额，传该字段直接拒绝。
3. 每次新请求必须经现有 DSH 人审展示 store、原总上限、累计用量、拟改后的总上限。工具/批准渠道接线在 agent-singularity，task-runtime 拥有校验及有效限额计算，Task 事件保存批准来源和扩额事实；runtime 不导入 evolution。服务消费可信批准渠道结果，模型和公开直调不能自填批准字符串越权。root grant 和 gate 只放行此窄入口，不开放业务写或通用 spawn。
4. 复用 Task store，增加一种预算追加事实；以 store+requestKey 幂等，保存原上限、批准后的上限、请求内容身份及批准引用。同 key 同内容返回已有结果，不再次审批/追加；异内容拒绝。批准后在 store 串行重检原上限，期间已被另一请求改变则本次拒绝，不能隐式重算授权额度。拒绝/取消零预算事件、零新 Run。
5. 初始预算仍按原根起点/部署配置解析；已批准维度随后以持久的绝对上限为准，缺省维度保留原值。重启不按当前时间重算 deadline、不回退到旧上限、不清空用量。公共解析器和所有准入/driver/watchdog/replay 路径消费同一有效限额，禁止另有一份旧根截止判断。每 Run 自身限时不被扩额重置；已终态 Run 不重开，正在运行者仅更新其根限额约束。
6. 扩额只改变允许执行的资源上限，不隐式恢复/派发/创建候选、不提高工具权限。已有 replay 是本票执行消费者：过期时拒绝，人批准后可在原 store 开始实验新 Run；旧任务仍终态。A6 的新尝试以后直接复用此能力，不再造恢复专属预算或默认豁免。

删除把 reviewer 与业务截止绑定的指引，以及扩额后仍硬读原配置截止的重复判断。不增加额度策略分类、自动审批、定时重试、成本预测或新平台。保持现有可执行硬限额与软观测的区别，不把 maxRuns 或 watchdog 宣称成精确 token 成本硬封顶。

## 验收

| 编号 | 必须证明的结果 |
|---|---|
| K4-1 | 原根已截止且 Run 数用尽，现有真实 review 工具在 reviewer 有额度时能执行；reviewer 自身耗尽/超时仍停止，旧计数重启不清零，无假业务 Run。 |
| K4-2 | 经终态根会话申请总上限，人拒绝/取消零预算写；批准前 replay 拒绝，批准后真实 replay 可启动，仍沿原 verifier，原 Run/Review 不变。worker、跨 graph、自填授权、无字段/无效数值/非提升请求均拒绝。 |
| K4-3 | 扩额提交前后重开、同 key 重试不重复扩额；冲突内容拒绝。两个请求同一基线获批准时只有一个可提交；旧计数加新 Run 仍按总额耗尽，不从零计。 |
| K4-4 | 普通新批次、replay、显式恢复的现有执行入口均读同一有效限额；root deadline 延后不误被旧 watchdog 取消，per-Run 限时仍有效。扩额不唤活终态、不恢复业务写、不自动启动工作。 |
| K4-5 | 模型工具、服务、批准渠道和持久事实完整接线，查询零写；公共检查通过，A5/A6 文档改为消费本票规则，无新预算平台或重复账。 |
