# Research scope and evidence

Protocol `buckyball-transfer-v1` tests whether a frozen method improves paired success on the declared unseen tasks. It does not assume a positive result. The current contribution is an implementation hypothesis: Task contracts, responsibility boundaries and exact Run evidence may improve reusable feedback. This needs an information-equivalent raw-trace comparison to support a mechanism claim. Calling harness optimization “RSI”, adding agents or attaching a hardware repository is not evidence of novelty.

The following primary-source abstract pages were fetched on 2026-10-18. Descriptions below are limited to those abstracts. RRSI was additionally checked against local source commit `be50316e1db05914068a973f322770ef08ed7ba1`. This is a bounded positioning review, not a complete literature search or independent reproduction of the papers' numbers.

| Work | Optimized object or evaluation boundary | Implication for this experiment |
|---|---|---|
| [RRSI](https://arxiv.org/abs/2609.24972) | Frozen-model harness; proposal/selection regularization, history, critic and pruning; coding, workspace and engineering evaluation | The search constraints are prior work. Compare Task-structured feedback with information-equivalent raw facts under the same runtime and candidate opportunities. |
| [DSPy](https://arxiv.org/abs/2310.03714) | Declarative LM modules in text transformation graphs; compilation against a metric | Optimizing a modular LM system is established. A different graph vocabulary is insufficient evidence of a new capability. |
| [TextGrad](https://arxiv.org/abs/2406.07496) | Textual feedback on variables in compound computation graphs | Natural-language feedback on components is prior work. Measure the value of frozen responsibility and evidence references rather than claiming feedback itself is new. |
| [GEPA](https://arxiv.org/abs/2507.19457) | Reflective prompt evolution using trajectories and complementary candidates | Reflection, trial feedback and candidate selection are established. Report selection exposure and final unseen evaluation rather than only evolve gains. |
| [AFlow](https://arxiv.org/abs/2410.10762) | Code-represented agent workflows with connected LM nodes; search from execution feedback | Workflow optimization is prior work. Test evolving workflow against frozen-workflow local-asset optimization on the same Task runtime. |
| [Voyager](https://arxiv.org/abs/2305.16291) | Executable skill library, environment feedback and transfer to a new Minecraft world | Persistent skills and black-box improvement without weight updates are prior work. Distinguish reusable procedures from replaying task answers. |
| [Reflexion](https://arxiv.org/abs/2303.11366) | Verbal task feedback kept in episodic memory for subsequent trials | Reflective memory is prior work. Preserve counterexamples and test actual feedback value under equivalent information. |
| [MetaGPT](https://arxiv.org/abs/2308.00352) | Role-based multi-agent software workflows and intermediate result verification | Multi-agent decomposition is established. Compare responsibility and stopping behavior rather than counting agents. |
| [SWE-agent](https://arxiv.org/abs/2405.15793) | Agent-computer interface design for repository editing and test execution | Tool interfaces affect baseline capability. All groups receive the same legitimate tools and public domain material. |
| [SWE-bench](https://arxiv.org/abs/2310.06770) | Real repository issues, code changes and execution-based evaluation | Retain issue/source provenance and independent tests. Same-fix variants remain one leakage group. |
| [VerilogEval](https://arxiv.org/abs/2309.07544) | Verilog completions checked against golden transient simulation outputs | Functional correctness needs an independent reference. HDL completion results do not establish cross-layer compiler/DSA repair or PPA. |

Candidate comparison groups and decision rules are recorded in `protocol.json`. H0 versus the frozen champion is the first product test. Structured feedback, regularization and evolving workflow remain separate unverified hypotheses until their respective comparisons run. Missing resources may reduce the comparison set, but must also reduce the claim.

No concrete Buckyball defect cases, independent hidden oracles or final split have yet been frozen. The environment audit rejects incomplete recursive source dependencies; no domain-effect trials have run. Engineering adapter tests exercise Git export, patch restrictions, Bubble isolation and verdict classification using explicit synthetic fixtures. Those fixtures are not Buckyball pilot tasks, and their passing counts are not transfer evidence. A broader survey of hardware/compiler agents and newer benchmarks remains outside this bounded review; it is required before a novelty claim or paper title is finalized.
