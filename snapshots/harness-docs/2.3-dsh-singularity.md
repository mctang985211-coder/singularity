# Singularity

Singularity 在 DSH 的 session、skill、preset 和 MCP 底座上提供图式代理执行与可验证任务运行时。图节点承载会话；Task 定义目标和验收；TaskRun 记录一次执行。

当前架构、已实现边界和 Task/Skill 选择见 [工作指南](../packages/singularity/docs/singularity-harness-guide.md)，具体建设顺序见 [建设计划](../packages/singularity/docs/2026-09-20-vrtc-code-change-plan.md)。两者更新于 2026-09-21；历史实跑记录已单独归档。

默认方向：Task 声明 capability，Harness 派发前解析工具和 skill，子节点按需读取 skill 正文并自主执行或分解。当前解析器是配置查表；完整 skill 契约、父级组合验证和 blocked 恢复仍在建设计划中，不能把已有图式执行等同于完整 VRTC 闭包。

部署能力表见 `config.yml.example` 的 `task-runtime` 段，实际可用项以运行中的 `capability_list` 为准。BB 领域义务与参考分别在 `.agents/skills/bb-obligations/` 和 `.agents/skills/bb-pipeline/`；它们不规定固定步骤顺序。

包清单与开发命令见 [Singularity README](../packages/singularity/README.md)。
