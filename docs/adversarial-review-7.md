- 每个 `assertClosedKeys` 调用点要么是包装器，要么是**被交进 `nested.<member>` 的读者**，
  要么是不进账本的控制载体。它按每个 kind 的每个成员探测"对象成员被闭合却没被声明"的情况
  → **零例**。

**而且变异账本的头条数字是真的**（35 caught / 0 misses，**独立重跑过**）。

**但"一个来源"这个机制往外挪了第四次 —— 挪到了给它背书的账本上：**

**"读者被放宽会被抓住"的唯一证据，是门禁在一条合成规则上的自检腿** —— 那条腿，机制**保证会通过**，

## BLOCKING（三条，我都同意）

### B1 —— "围栏未闭合"检测器被**围栏长度**击败，而且它静默地藏住计数
`gates.mjs:844`：`if (/^\s*```/.test(line)) { fenced = !fenced; return }` —— **纯翻转，不记录定界符**。
于是用**四个或更多反引号**（或 `~~~`）开的围栏**不被同长度的闭合符识别**，里面的东西被当散文读……
然后因为"在围栏里"又被 `if (fenced) return` **整个跳过**。一对不匹配还会让文件剩余部分全部失明。

**实测**（真实树副本）：往 `docs/handoff.md` 追加
```
````
this tree has 99 gates
````
```
→ `ok tree-inventory`、**`gates: OK — 21 gates passed`**。
对照（同一副本）：同样的计数**不加围栏** → 红；放进**平衡的三个**反引号 → 静默（正确）；
四个反引号**开着不闭** → 红（正确，报"leaves a code fence open"）。
**所以"一个 ``` 不能让后面全部豁免"这条 finding 并没有关上** —— **一对四反引号就豁免一片，而且什么都不报。**

### B2 —— 声明为 record 的豁免**比印出来的边界宽**，而且它接受"什么都没记录"的 record
`gates.mjs:838-841`：`RECORD_DOCS` 的条目只要**文件里任何地方**出现一个带十六进制字母的 token 就**整份跳过**。
它**不要求**那是**本仓库**的 commit，也不要求它是个 commit。

- **在真实的六份 record 上**（逐 token 用 `git cat-file -e <token>^{commit}` 验）：
  **六份里有三份根本没有命名本树的任何 commit** —— `review.md` 命名的是 DSH checkout、
  旧 Singularity harness、RRSI checkout，**都不在本树**。按它自己写下的边界
  （"一个计数只属于它命名的那个 commit"），这些**不是任何东西的记录**，但实现给了它们**整份文件的豁免**。
  而 `review.md:322` 还带着一行本来会开火的计数（"7/7 门禁通过"）。
- 于是**一个错误的数字现在可以合法地住在三个地方**：活文档里任何带 commit 形状 token 的行、
  **六份整文件豁免中的任何一份**（其中三份不记录本树的任何 commit）、以及四反引号围栏里。

（每行那半个限制**是**写下来的；**整文件那半个没有写在任何地方**，而它是更宽的那个。）

### B3 —— 第六轮的耐用性不变量**原样开着**，而且写在门禁运行时**真的发生了**
第六轮的两条构造**都没有被处理**。在 HEAD 上复现，`tsc` 干净，**`gates: OK — 21 gates passed`**：
- `export { writeFile } from 'node:fs/promises'`（转发子句）+ 从该模块 import 并模块级调用
  → `ok no-durable-writer`，**而文件之后确实存在** —— **sweep 在"本该注意到它的那一次运行里"执行了这次写。**
- `execFileSync('sh', ['-c', 'echo … > /tmp/…'])` → `ok no-durable-writer`，文件被写。

检测器唯一的门是 `import` 这个关键字（`gates.mjs:428`），而"通用进程执行器"不在任何闭合集合里。
**审查者的措辞**：这不是新 finding，是**第六轮 blocking 级、两个提交之后仍然开着**，
而它挡的是**那句声称** —— `gates.mjs:44-48` 说写"不只是通过了门禁：它**执行了**这次写……
在任何人读到输出之前"，**这是真的，而且读起来像一个屏障，但它不是。**

## HIGH

- **H1 —— 便宜的路挪了第三次，而且印出来的披露现在不完整。**
  `scriptFiles()` **只收 `entry.name.endsWith('.mjs')`**，并跳过名字以 `.` 开头的条目。
  实测：`scripts/zz-big.js`、`.cjs`、`.ts`、`.probes/zz-big.mjs` 各 **5,000 行**
  → **`ok evidence-budget`、`ok source-size`、21/21 全绿**，**而打印出来的收费数字纹丝不动**。
  **两万行不被收费，而一个 5,000 行的 `scripts/zz-big.mjs` 会开火。**
  同机制下 `tests/vectors/strategy-decision-vectors.json`（503 行）与 `README.md`（108 行）也不收费，
  而门禁印出来的"未收费"清单**没有点名它们**。
- **H2**：`COUNT_CLAIM` 要求数字与量词**相邻**，所以 `21 个门禁`（有空格）、`326 test files` 都不是 claim。
